## ✨ Features

- Search all 250 countries
- Details: capital, region, population, area, languages and timezones
- Save countries to favorites
- Context API, React Router and Tailwind CSS

## 🚀 Getting Started

**Prerequisites:** [Node.js](https://nodejs.org/) 18 or newer

**Install and run**

```bash
git clone https://github.com/miladmo68/Countries-Info-App.git
cd Countries-Info-App
npm install
npm run dev
```
