## ​ Features

| Feature | Description |
| --- | --- |

|  **Detailed View** | Click on a country to see full details—population, region, capital, flag, etc. |

## ​ Getting Started

```bash
# 1) Clone the repository
git clone https://github.com/miladmo68/Countries-Info-App.git
cd Countries-Info-App

# 2) Install dependencies
npm install

# 3) Run development server
npm run dev

# 4) Build for production
npm run build
